# DEMO

## Live Demo Overview

IntelliFlow AI is an enterprise customer support intelligent workflow automation agent. A live demonstration of the project is available to showcase its capabilities in analyzing support tickets, detecting anomalies, and generating contextual actions and reports.

## Access the Live Demo

-   **Live Demo URL:** [https://initialflowagent.netlify.app/](https://initialflowagent.netlify.app/)

## Demo Notes

The interface is designed as a live-style support operations system with a visual workflow, execution logs, and analytics views. It provides a realistic user experience of how an intelligent workflow automation agent can assist enterprise customer support teams.

## Key Features to Observe in the Demo

-   **Overview Dashboard:** Monitor support workflow in real-time.
-   **Data Sources:** See how Snowflake tables and CSV uploads are integrated.
-   **Agent Skills:** Observe modular AI processing in action.
-   **Workflow Builder:** Understand the automation logic.
-   **Executions History:** Track completed runs.
-   **Anomaly Detection:** Identify high-risk tickets.
-   **Insights and Reports:** Review business analysis.

## Current Demo Limitation

During development, the application was successfully integrated with Snowflake. However, the current demo uses API responses because the Snowflake trial/credit limit has expired. The project is connected to the Snowflake customer support dataset and was designed to process enterprise support records from that source. The demo effectively showcases the system's capabilities using this fallback mechanism.
