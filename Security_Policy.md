# Security Policy

## Supported Versions

This project is maintained for demo and educational purposes. Security updates will be applied to the latest available version when needed.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it immediately by email to:

mrspaceresearcher@gmail.com

Please include the following details in your report:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Any affected files, pages, or features.
- Screenshots, logs, or proof of concept if available.

## Response Time

Reports will be reviewed as soon as possible. If the issue is valid, the project owner will investigate and work on a fix in a reasonable time frame.

## Responsible Disclosure

Please do not publicly disclose security vulnerabilities before they have been reviewed and addressed. Responsible disclosure helps keep the project and its users safe.

Thank you for helping protect this project.
