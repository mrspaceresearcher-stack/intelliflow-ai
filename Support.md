# Support

## Support Overview

This project is an AI-powered workflow platform for customer support ticket analysis, anomaly detection, decision-making, and automated reporting. It works with Snowflake-backed data, CSV uploads, and fallback sample data when live access is unavailable.

## Bug Report Process

To report a bug, please include the following details:
- A short summary of the issue.
- Steps to reproduce it.
- Expected behavior.
- Actual behavior.
- Screenshots or logs if available.
- Any ticket ID, workflow run ID, or API response that helps debugging.

If the bug involves Snowflake access, please mention whether the issue happened during live query execution, CoCo CLI usage, or fallback data loading.

## Feature Request

When requesting a feature, please describe:
- What problem it solves.
- Who will use it.
- Why it matters.
- Any UI, workflow, or data integration changes needed.
- Whether it should apply to the Ticket Analyzer, Risk Detector, Decision Agent, or reporting flow.
